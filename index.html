Rclone Personal

Rclone Personal is a private, non-commercial configuration of Rclone, an open-source file transfer application.

It is used by its owner to access and download files from Google Drive, including folders shared with the owner's Google account.

Google Drive access is read-only. This application does not modify or delete files stored in Google Drive.

The application is intended solely for personal use and is not offered as a public service.
